# BarringtonVPN — Android (черновик, Этап A)

Это минимальный каркас приложения: проверка, что сборка через GitHub Actions
работает, + экран проверки статуса аккаунта по токену подписки.
VPN-подключение будет добавлено на Этапе B.

## Как собрать APK (без Android Studio)

1. Зайди на github.com, создай новый репозиторий (Create a new repository).
   Имя любое, например `barringtonvpn-app`. Public или Private — не важно.
2. На странице репозитория нажми "Add file" → "Upload files".
3. Перетащи туда ВСЮ папку `BarringtonVPNApp` целиком (всё её содержимое,
   с сохранением структуры папок — современные браузеры это поддерживают
   при drag-and-drop папки). Нажми "Commit changes".
4. Перейди на вкладку "Actions" в репозитории. Должен автоматически
   запуститься workflow "Build APK" (если нет — нажми на него слева и
   "Run workflow").
5. Подожди 3-7 минут. Когда появится зелёная галочка — открой этот запуск,
   внизу страницы будет раздел "Artifacts" со ссылкой
   "BarringtonVPN-debug-apk" — скачай его (это zip, внутри — файл .apk).
6. Перенеси .apk на телефон, открой — Android спросит про установку из
   неизвестных источников, разреши. Готово.

Если сборка упадёт красным крестиком — открой лог упавшего шага и пришли
мне текст ошибки, я поправлю код.
